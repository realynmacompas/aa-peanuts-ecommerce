A responsive e-commerce website developed for **A&A Peanuts** as a collaborative academic project. The system enables customers to browse products, place orders, and complete purchases online while providing administrators with tools to manage products, orders, inventory, and users.

> **Project Type:** Academic Team Project

---

## Features

### Customer Side
- User registration and login
- Product catalog and search
- Shopping cart functionality
- Checkout process
- GCash and Cash on Delivery (COD) payment options
- Order tracking

### Admin Side
- Dashboard
- Product management
- Inventory management
- Order management
- User management
- Sales reports

## Installation

1. Clone the repository.

```bash
git clone https://github.com/realynmacompas/aa-peanuts-ecommerce.git
```

2. Move the project to your XAMPP `htdocs` folder.

3. Import the MySQL database into phpMyAdmin.

4. Start Apache and MySQL using XAMPP.

5. Open your browser and visit:

```
http://localhost/AAPEANUTS
```
